# Icons8 Cat Icon — Playwright E2E Test

Небольшой E2E-тест на Python, Playwright и pytest. Он открывает страницу результатов Icons8 для `cat`, проверяет, что результаты показаны, открывает первую найденную иконку и проверяет, что её изображение отображается.

## Требования

- Python 3.10 или новее
- Интернет-соединение

## Ус��ановка и запуск в Windows

Откройте Command Prompt или терминал в папке проекта и выполните:

```cmd
py -m venv .venv
.venv\\Scripts\\activate
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m pytest -v test_icons.py
```

Тест сохраняет скриншот `icons8-cat-result.png` в текущую папку. Лог успешного запуска приложен в [`test-result.txt`](test-result.txt).

## Ограничение

Во время отладки поиск через поле на главной странице Icons8 в автоматизированном браузере не запускался после нажатия Enter: поле очищалось, а URL оставался прежним. Поэтому тест открывает страницу результатов `/icons/set/cat` напрямую. Он проверяет наличие результатов и открытие иконки, но не проверяет отправку поискового запроса через поле на главной странице.

## Использование GitHub Copilot

GitHub Copilot использовался для подготовки тест��, подбора локаторов и анализа ошибок при запуске. После пробных запусков пришлось уточнить проверки и локаторы. Локальный тест прошёл: `1 passed in 12.47s`.
